# 📰 Fake News Detection System

A beginner level machine learning-based web application that detects whether a news article is **real or fake** using natural language processing techniques.

---

## 🚀 Tech Stack

- **Frontend:** React  
- **Machine Learning:** Python (Scikit-learn / NLP models)  

---

## 🧠 How It Works

1. User enters a news article or headline  
2. Text is processed using NLP techniques  
3. Model analyzes patterns and features  
4. System predicts whether the news is:
   - ✅ Real  
   - ❌ Fake
## ⚠️ Current Limitation

- The model currently works only on the **test dataset** used during development.
- It is **not yet generalized for real-world news inputs**.
- Predictions may not be accurate for unseen or live data.

> This project demonstrates the implementation of a fake news detection model, but further improvements are needed for real-world deployment.
